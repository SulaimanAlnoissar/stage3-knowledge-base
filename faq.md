# GDG KSU FAQ

## Overview

This file contains frequently asked questions and answers that can help the chatbot respond to common student questions about GDG KSU, its activities, and its technical content.

## General Questions

### What is GDG KSU?

GDG KSU is a student club at King Saud University for aspiring developers. It connects theory with practice through workshops, collaborative projects, and technical activities.

### What is the main goal of GDG KSU?

The main goal is to help students learn, collaborate, take initiative, and build real technical impact through practical experiences.

### Who is the target audience of GDG KSU?

The club mainly targets students interested in development, technology, artificial intelligence, and practical technical projects.

## Activities Questions

### What types of activities does GDG KSU organize?

GDG KSU organizes technical workshops, company visits, in-person sessions, community initiatives, and educational social media content.

### What was the Vibe Coding workshop about?

The Vibe Coding workshop discussed the concept of coding with AI, how AI can improve the programming experience, and how to choose suitable tools and methods.

### What was the Saudi Azm and B-IT visit about?

The visit introduced members to work environments, professional experiences, and technical practices inside the industry.

## Technical Questions

### What is an API?

An API is a way for applications to communicate and exchange data. It allows one program to send requests and receive responses from another service.

### What is GitHub?

GitHub is a platform for managing software projects, sharing code, tracking versions, and collaborating with others.

### What is an LLM?

An LLM, or Large Language Model, is an AI model trained on large amounts of text. It can understand and generate human-like language.

### What is Docker?

Docker is a tool that runs applications inside containers. Containers help applications run consistently across different environments.

### What is Postman?

Postman is a tool used to test APIs by sending requests and viewing responses without needing to write full code.

### What is Two-Factor Authentication?

Two-Factor Authentication, or 2FA, is a security method that adds an extra verification step after the password.

## Chatbot Questions

### How can the chatbot use the Knowledge Base?

The chatbot can search the Knowledge Base, retrieve the most relevant information, and send it with the user's question to Gemini.

### Why does the chatbot need a Knowledge Base?

The Knowledge Base helps the chatbot answer using trusted club information instead of relying only on general AI knowledge.

### What types of files are useful for the Knowledge Base?

Markdown files are useful for written explanations, while JSON files are useful for structured data and metadata.
