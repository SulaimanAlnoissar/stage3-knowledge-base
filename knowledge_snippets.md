# GDG KSU Knowledge Snippets

## Overview

This file contains short educational knowledge snippets collected from GDG KSU social media content. These snippets can help the chatbot answer simple technical questions and explain common tools and concepts to students.

## API

An API is a way for applications to communicate and exchange data.

In programming, the main function of an API is to connect two applications together so they can send and receive information.

Example:
A Python program can use an API to send a request to Gemini and receive a response.

## GitHub

GitHub is a platform for managing software projects and sharing code.

It helps developers:

- Save different versions of their code
- Collaborate with team members
- Organize project files
- Share projects publicly
- Build a technical portfolio

GitHub is useful for keeping code organized and making projects easier to manage.

## VirusTotal

VirusTotal is a free online tool used to scan files and links.

It helps users check whether a file or URL may be unsafe before opening it.

Main uses:

- Scan suspicious files
- Check links before visiting them
- View security reports from multiple security tools

## Claude Code

Claude Code is an AI coding tool that works inside the terminal.

It can help developers understand, edit, and work with code directly from their development environment.

Main features:

- Understands the full project context
- Can edit more than one file
- Helps with coding tasks through terminal commands
- Works like an AI coding assistant

## Gamma

Gamma is an AI tool used to create presentations and visual content.

It helps users turn ideas into organized slides and designs.

Main features:

- Creates presentations quickly
- Suggests layouts and visuals
- Helps organize ideas
- Useful for students and teams creating visual content

## Docker

Docker is a tool used to run applications inside containers.

A container includes the application and its requirements so it can run in different environments without many setup issues.

Main benefits:

- Makes deployment easier
- Reduces environment problems
- Allows projects to run consistently
- Useful for developers and software teams

## LLM

LLM stands for Large Language Model.

It is an artificial intelligence model trained on large amounts of text data. It can understand and generate human-like language.

Examples of LLMs:

- Gemini
- ChatGPT
- Claude

LLMs can answer questions, summarize text, write code, and help with many language-based tasks.

## Two-Factor Authentication

Two-Factor Authentication, or 2FA, is a security method used to protect accounts.

It adds an extra step after entering the password, such as a verification code.

This makes accounts safer because a password alone is not enough to log in.

## Postman

Postman is a tool used to test APIs.

It helps developers send requests, view responses, and check if an API works correctly.

Main features:

- Send different types of API requests
- View responses clearly
- Organize requests into collections
- Test APIs without writing full code

## Cloud

Cloud is a service that allows users to store files and run services over the internet instead of only using a local device.

Examples:
Google Drive and Google Docs use cloud storage, so files can be accessed from different devices.

Cloud services help keep data available online and easier to access.

## Recursion

Recursion happens when a function calls itself.

If recursion does not have a stopping condition, it can keep calling itself until the program reaches a stack overflow error.

A stopping condition is important to prevent infinite recursive calls.
